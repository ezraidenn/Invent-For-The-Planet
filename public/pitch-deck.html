⚙️ Tecnología

Cómo funciona

1. Generador publica

Foto + IA clasifica material, estima kg. Geolocalización automática.

2. Smart Route Builder

Algoritmo de grafos (nearest-neighbor + 2-opt) genera ruta óptima.

3. Recolección verificada

Per-stop: llegar → pesar → foto → confirmar. Todo con timestamps.

4. Entrega en centro

Pesaje oficial, foto, payout automático 60/25/15 split.

5. Ciclo completo

Material → nuevo recurso → cadena alimentaria. Trazabilidad total.

Stack

Next.js 14 · React · TypeScript · Tailwind · PostgreSQL · Drizzle ORM · Google Maps · Ably Realtime

Verificación

Foto comprimida on-device (JPEG 55%, max 800px) · Pesaje por stop · Timestamps inmutables · Notificaciones real-time

Algoritmos

Scoring multi-factor · Haversine distance · Nearest-neighbor heuristic · 2-opt improvement · Constrained optimization
